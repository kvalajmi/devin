# نظام إدارة القروض - هارموني إكسل

## 📋 نظرة عامة
نظام ويب شامل لإدارة القروض والاستثمارات، مصمم ليحل محل ملفات الإكسل التقليدية بواجهة حديثة وسهلة الاستخدام.

## ✨ الميزات الرئيسية
- 📊 **لوحة تحكم تفاعلية** - إحصائيات وتحليلات في الوقت الفعلي
- 👥 **إدارة العملاء** - معلومات شاملة لكل عميل
- 💰 **تتبع الدفعات** - سجل مفصل لجميع المعاملات
- 📄 **إدارة المرفقات** - رفع وعرض وطباعة الوثائق
- 📈 **تحليلات مالية** - حسابات الربح والخسارة
- 🖨️ **طباعة متقدمة** - تقارير وملفات قابلة للطباعة
- 📱 **تصميم متجاوب** - يعمل على جميع الأجهزة

## 🛠️ التقنيات المستخدمة
- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM
- **Icons**: Lucide React
- **Charts**: Recharts
- **Build Tool**: Vite
- **Date Handling**: date-fns

## 🚀 التشغيل السريع

### المتطلبات
- Node.js (الإصدار 16 أو أحدث)
- npm أو yarn

### التثبيت والتشغيل
```bash
# تثبيت المكتبات
npm install

# تشغيل الخادم المحلي
npm run dev

# بناء المشروع للإنتاج
npm run build

# معاينة النسخة المبنية
npm run preview
```

## 🎯 الصفحات الرئيسية

### 1. لوحة التحكم (Dashboard)
- إحصائيات عامة للنظام
- رسوم بيانية تفاعلية
- ملخص المعاملات اليومية

### 2. تفاصيل العميل (ClientDetails)
- معلومات شاملة للعميل
- سجل الدفعات والمصروفات
- إدارة المرفقات والوثائق
- حسابات الربح والخسارة
- طباعة التقارير

### 3. المستثمرين (Investors)
- قائمة المستثمرين
- تفاصيل الاستثمارات

### 4. معاملات المستثمرين (InvestorTransactions)
- سجل معاملات المستثمرين
- تحليلات الأرباح

## 🔧 الميزات المتقدمة

### إدارة المرفقات
- رفع ملفات متعددة الأنواع (PDF, JPG, PNG, DOC, XLS)
- عرض المرفقات في نافذة منبثقة
- طباعة فردية أو جماعية
- تصنيف المرفقات حسب النوع

### الحسابات المالية

- مؤشرات تقدم للعمليات الطويلة
- تحسين الذاكرة والعرض
